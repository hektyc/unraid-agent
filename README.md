# Unraid MCP Server

Feature-rich, safety-enhanced Unraid MCP server built with the best modern tech stack.

- Read-only mode support with granular action toggles
- Safety guards on all destructive operations
- Universal AI client support (Claude, Codex, OpenCode, Kilo, VS Code, etc.)
- Three transport modes: stdio, streamable-http, sse
- Real-time WebSocket subscriptions for live telemetry
- Lightweight TypeScript with minimum resource footprint

## Setup

See [.env.example](.env.example) for configuration.

## Development

- `dev` is the primary working branch
- `main` is for stable, tested releases  
- Production versions start at `0.0.1` and auto-increment with each merge to main
